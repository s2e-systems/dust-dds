# Derive macro for `DdsType`

This package provides the `DdsType` derive macro to support [dust-dds](https://github.com/s2e-systems/dust-dds).

For a detailed description of the options available, container/field attributes, struct inheritance, unions, and usage examples, please refer to the [DDS Type Definition Guide](https://github.com/s2e-systems/dust-dds/blob/main/dds/docs/type_support.md) and the documentation of the main [dust_dds](https://crates.io/crates/dust_dds) crate.
